    3. Kiến thức Flutter cần nắm

    Học theo cụm, mỗi cụm map trực tiếp vào file thật trong project.

    Dart language

    • final, const, named params
    • null safety: ?, ??, !
    • async/await, sealed class, pattern matching

    Widget system

    • StatelessWidget, StatefulWidget
    • build(), widget tree, rebuild
    • initState(), dispose()

    Layout

    • constraints: cha đưa constraint, con chọn size
    • Row, Column, Expanded
    • SafeArea, LayoutBuilder, scroll

    State & Form

    • ChangeNotifier giống store nhỏ cho một màn
    • TextEditingController giữ input
    • Form, validator, loading/error state

    Navigation

    • go_router giống React Router
    • route constants trong app_router.dart
    • sau này thêm auth redirect/guard

    Data & Production

    • DTO to Domain mapping
    • Repository as single source of truth
    • secure storage, tests, logging, flavors, CI
